1. XSS vulnerability: Reflected XSS

- [views.py]: the aforementioned methods use a parameter 'director', which is an open variable - xss is exploited by attaching '?director=script>alert("hello.")</script>'to get requests for vulnerable websites
- director|safe in templates 'item-single.html', 'gift.html': the safe tag disables the default auto escape in Django.
- Using'safe' permits the insertion and execution of any script>/script> when supplied in the URL's 'director' query parameter.


-> Examples:
-> '/buy.html?director=<script>alert("hello.")</script>' [always displays alert(str)]


FIX: fixed by removing 'safe' tag from 'director' attribute in templates, defaulting to django's escape tag functionality
